
    ##  [1] 2 3 1 2 3 1 2 3 1 2

- vec_logical has values of 0 and 1, creating binary variables based if
  the function is true (rnorm \> 0)
- vec_char has NA values by coercion because they are letters (cannot be
  converted to numbers)
- vec_factor has values from 1 to 3 (ranking low, medium, and high
  levels)

It explains why taking the mean did not work for vec_char and
vec_factor. The variable vec_logical did take a mean, however it would
be values between 0 and 1 since it is a binary variable.
